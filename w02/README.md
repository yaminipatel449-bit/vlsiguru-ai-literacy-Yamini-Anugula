## Overview
This directory contains my research deliverables for Week 02: Machine Learning Foundations. The objective of this week is to establish a strong mental model of how machines learn from data—spanning AI/ML taxonomy, data representations, learning paradigms, task types, model anatomy, evaluation metrics, failure modes, framing criteria, and semiconductor applications.

## Directory Structure
- `mission_01_ai_ml_landscape.md`: AI, ML, Deep Learning, GenAI, and LLM hierarchy map and distinctions.
- `mission_02_data.md`: Samples, features, labels, and data quality impacts with an illustrative 6-row dataset.
- `mission_03_learning_approaches.md`: Comparison of Supervised, Unsupervised, Reinforcement, and Self-Supervised Learning.
- `mission_04_ml_tasks.md`: Task types breakdown (Classification, Regression, Clustering, Anomaly Detection, etc.) with input/output examples.
- `mission_05_model_anatomy.md`: Model lifecycle flow diagram (Data -> Training -> Parameters -> Inference) and linear regression intuition.
- `mission_06_evaluation.md`: Data splitting (Train/Val/Test), generalisation, overfitting/underfitting, and class imbalance metrics.
- `mission_07_failure_modes.md`: Failure modes analysis covering data bias, data leakage, and concept drift.
- `mission_08_when_to_use_ml.md`: Comparative analysis of rule-based software vs. ML solutions for a floorplanning routing problem.
- `mission_09_semiconductor_case_study.md`: Semiconductor case study on ML-driven PPA and routability congestion prediction.
- `sources.md`: Citations and claim support mapping.
- `reflection.md`: Final weekly reflection on key learnings and confusing concepts.
